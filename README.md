# modern-traQ

[traQ](https://github.com/traPtitech/traQ) の新しい Web クライアント（React + Vite + TypeScript）。

```bash
npm install
npm run dev                                       # q.trap.jp に接続
TRAQ_ORIGIN=http://localhost:3000 npm run dev     # ローカルの traQ に接続
```

`/api` は Vite の dev server が `TRAQ_ORIGIN` へプロキシします（WebSocket 含む）。

## デスクトップアプリ (Electron)

```bash
npm run app        # ビルドしてそのままアプリとして起動
npm run app:dist   # macOS の .app を release/mac-arm64/traQ.app に作る
```

アプリの中で `localhost:47321` に小さなサーバーを立て、ビルド済みの画面を配信しつつ `/api` (WebSocket 含む) を `TRAQ_ORIGIN` (既定 `https://q.trap.jp`) へ中継します。開発サーバーと同じ構成なので、ログイン状態はアプリ内に保存されます。外部リンクは既定のブラウザで開きます。アプリとタブのアイコンは q.trap.jp と同じもの (`public/img/icons`, `build/icon.png`) です。署名していないので、ほかの Mac では初回だけ右クリック →「開く」が必要です。

## 操作

| 操作 | |
|---|---|
| `⌘K` / `Ctrl+K` | チャンネルへ移動（あいまい検索） |
| `⌘Z` / `Ctrl+Z` | 直前の操作を取り消す（編集・スタンプ・ピン・お気に入り・通知設定など。編集はトーストを出さず ⌘Z のみ。削除は取り消せない） |
| `Enter` / `⌘Enter` (Ctrl+Enter) | 改行 / 送信 (編集中は保存) |
| 空の投稿欄で `↑` | 自分の最後のメッセージを編集 |
| `@` / `:` | ユーザー / スタンプの補完 |
| 貼り付け・ドロップ | ファイル添付 |
| ヘッダーの 📌 / 🔍 | ピン留め一覧 / メッセージ検索（結果をクリックで元の位置へ） |
| 検索の演算子 | `from:@user` `to:@user` `in:#path` `after:2024-01-01` `before:2024-12-31` `has:image\|video\|audio\|url\|file` `is:bot` `cites:<メッセージID>`（メッセージのツールバーの 💬❝ からも） `sort:old\|updated`。検索欄の下のボタンでも組み立てられ、条件はチップで表示（× で外す、使えない条件は赤い取り消し線） |
| サイドバー上部の アクティビティ / クリップ | 購読チャンネルの新着 / クリップしたメッセージ |
| アイコン・名前をクリック | ミニカード → プロフィールパネル（投稿数・よく使うスタンプ・最近の投稿） |
| サイドバー上部の ⚙ | 設定（`/settings/profile` など）: プロフィール・ホーム・テーマ・通知・パスワード・セッション |
| サイドバーの 🏠 / # | ホーム（ホームチャンネル・未読のある DM・未読のあるチャンネル。メンション/引用/通知オンを上にまとめる）/ すべてのチャンネルのツリー（上にお気に入りだけの木。分岐しない親はまとめて1行） |
| ヘッダーの 🏠 | このチャンネルをホームに設定。`/` を開くとホームから始まる |
| 引用カードをクリック | 引用元のメッセージへ移動 |
| `$...$` / `$$...$$` | 数式を KaTeX で表示 (S-UI と同じ記法) |
| 投稿欄の 😊 | スタンプを選んで `:name:` を挿入 |
| メッセージの ❝ (引用) | 投稿欄の上に引用チップとして積む。送信時に本文の末尾へ URL を付ける（traQ は末尾の URL だけを埋め込みにするため） |
| スタンプにカーソル / 長押し | 誰が何回押したかのカード（自分は強調） |
| スタンプピッカーのタブ | 最近使ったもの / 各スタンプパレット / すべて。⚙ からパレット編集へ |
| 設定 → スタンプパレット | パレットの作成・名前変更・スタンプの追加と並べ替え（ドラッグ）・削除（削除は即時） |
| 画面右端の縦の列 | 見ている人（青い輪は入力中、薄いのは別タブ）。顔でユーザーカード、上の 👁 で見ている人 / 通知を受け取っている人の一覧。狭い画面ではヘッダーの 👁 人数 |
| 名前の横の学年 | type が grade のグループ（S-UI と同じ）。押すとグループ詳細 |
| 古いメッセージへのジャンプ | 遡りきれないときは前後だけを読み込む。下にスクロールで続き、↓ で最新へ |
| 投稿欄の上の ●●● | 誰かが入力中 |
| サイドバーの 👤🔍 | ユーザー検索（人 / BOT / グループの切り替えとオンラインで絞り込み） |
| グループ管理 | 👤🔍 → グループ → 「新しいグループ」で作成。管理しているグループの詳細では名前・種類・説明・アイコン・メンバー追加・役割・管理者（👑）・メンバーを外す・削除がその場でできる（削除以外は取り消し可。削除は即時。自分の管理者権限を外すときだけ2回押し） |
| プロフィールのタブ | 投稿 / グループ / タグ。グループ・タグを押すと詳細（メンバー一覧、← で戻る） |
| ツリーの行にホバーして `+` | 子チャンネルを作成（ツリーは毎回閉じた状態で始まり、今いるチャンネルを含む親は青くなる） |
| トピックをクリック | トピックを編集 |

メッセージ・スタンプパレット・グループの削除はすぐにサーバーへ送り、取り消せません。そのほかの操作はトーストか `⌘Z` で取り消せます（トーストにカーソルを乗せるとタイマーが止まります）。

デスクトップ版ではトラックパッドの2本指の横スワイプで戻る/進む（右で戻る）。`⌘[` / `⌘]` とマウスの戻る/進むボタンも使えます。

## 構成

- `src/store.ts` 状態（zustand）と API 操作、取り消しスタック
- `src/realtime.ts` WebSocket（自動再接続、取りこぼし再取得）
- `src/ChannelView.tsx` ヘッダー・タイムライン・投稿欄
- `src/Message.tsx` メッセージ、スタンプ、埋め込み、インライン編集
- `src/Sidebar.tsx` / `src/Overlays.tsx` チャンネルツリー、DM、パレット、スタンプピッカー、ユーザーカード、トースト
- `src/Panels.tsx` 検索・ピン留め・クリップ・アクティビティ・プロフィールの右パネル
- `src/Settings.tsx` 設定画面
- `electron/main.cjs` デスクトップアプリ (配信と API 中継)
